# Catálogo visual MVP

Este diretório contém seis coleções e 24 referências visuais selecionadas para validar o configurador.

As imagens não são materiais PBR de produção. Não possuem escala física validada, repetição seamless, AO, Normal Map ou Roughness Map.

A ampliação do catálogo e a migração para armazenamento externo ficam condicionadas à validação do MVP.
